# SNNSM

This repository contains the MATLAB source code used to generate the **SMAP-NNsm Seamless Soil Moisture (SNNSM)** dataset.

SNNSM is a daily global surface soil moisture product generated by combining SMAP and NNsm using Extended Triple Collocation (ETC)-derived error variances, followed by spatio-temporal kriging (STK) gap filling.

## Workflow

The main processing steps are:

1. **ETC analysis**  
   Estimate pixel-wise random error variances for SMAP and NNsm using two ETC triplets:
   - SMAP + ASCAT + GLDAS Noah
   - NNsm + ASCAT + GLDAS Noah

2. **Soil moisture fusion**  
   Merge SMAP and NNsm using inverse-error-variance weighting.  
   When only one product is available, the available observation is retained.

3. **STK gap filling**  
   Fill remaining missing values over thawed soil using local ordinary spatio-temporal kriging with a product-sum covariance model.

## Requirements

- MATLAB R2024a or later
- Input soil moisture datasets must be preprocessed to a common spatial grid and daily time step.

## Usage

Before running the scripts, update the input and output paths in the configuration section of each MATLAB file.

Recommended execution order:

```text
ETC analysis
    ↓
SMAP-NNsm fusion
    ↓
STK gap filling
    ↓
SNNSM
```

## Output

The final STK script generates yearly soil moisture files containing:

```text
fusion_SM_STK
```

which represents the gap-filled SNNSM soil moisture field.
